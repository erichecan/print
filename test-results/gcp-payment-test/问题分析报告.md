## 🔍 问题详细分析

### 问题 1: 未找到添加购物车按钮

**错误信息**: `未找到添加购物车按钮`

**影响范围**: 
- 成功支付测试失败
- 3D Secure 测试失败

**可能的原因**:

#### 1. 按钮选择器不匹配
根据代码分析，商品页面可能使用以下按钮文本：
- `"Add to cart"` (英文)
- `"加入购物车"` (中文)
- `"添加到购物车"` (中文变体)

测试脚本尝试的选择器：
```python
add_button_selectors = [
    'button:has-text("Add to Cart")',  # 注意：实际代码中是 "Add to cart" (小写)
    'button:has-text("加入购物车")',
    'button:has-text("添加到购物车")',
    'button[class*="add-to-cart"]',
    ...
]
```

**问题**: 选择器中的 `"Add to Cart"` 与实际代码中的 `"Add to cart"` 大小写不匹配！

#### 2. 按钮可能被禁用
根据代码分析，添加购物车按钮在以下情况会被禁用：
- 未选择商品变体（颜色、尺寸）
- `!selectedVariant` 为 true
- `isAddingToCart` 为 true

代码示例：
```typescript
<button
  onClick={handleAddToCart}
  disabled={isAddingToCart || !selectedVariant}
>
  {isAddingToCart ? 'Adding...' : 'Add to cart'}
</button>
```

**问题**: 测试脚本可能没有正确选择商品变体，导致按钮被禁用且不可见。

#### 3. 页面加载时间不足
测试脚本在访问商品页面后只等待了 5 秒：
```python
page.goto(product_url, wait_until='networkidle', timeout=30000)
time.sleep(5)  # 可能不够
```

**问题**: 如果页面是动态加载的（React），可能需要更长时间才能完全渲染。

#### 4. 页面结构可能不同
代码中有多个商品详情组件：
- `ProductDetailContent` - 使用 "Add to cart"
- `PixelPerfectProductDetail` - 使用 "加入购物车"
- `BuyBox` - 使用 "Add to cart"

**问题**: 不同商品可能使用不同的组件，按钮位置和选择器可能不同。

## 🛠️ 解决方案

### 方案 1: 修复按钮选择器（立即修复）

**问题**: 选择器大小写不匹配
```python
# 当前（错误）
'button:has-text("Add to Cart")'  # 大写 C

# 应该改为
'button:has-text("Add to cart")'  # 小写 c
```

### 方案 2: 确保先选择商品变体

**问题**: 按钮可能因为未选择变体而被禁用

**解决**: 在选择按钮之前，确保：
1. 先选择颜色（如果存在）
2. 再选择尺寸（如果存在）
3. 等待按钮变为可用状态

```python
# 改进的选择逻辑
# 1. 等待变体选择器加载
await page.wait_for_selector('[class*="color"], button[class*="color"]', timeout=10000)

# 2. 选择颜色
color_btn = page.locator('[class*="color"]').first()
if color_btn.count > 0:
    await color_btn.click()
    await page.wait_for_timeout(1000)  # 等待状态更新

# 3. 选择尺寸
size_btn = page.locator('[class*="size"]').first()
if size_btn.count > 0:
    await size_btn.click()
    await page.wait_for_timeout(1000)

# 4. 等待按钮变为可用
await page.wait_for_selector('button:has-text("Add to cart"):not([disabled])', timeout=10000)
```

### 方案 3: 增加页面等待时间

**问题**: 页面可能未完全加载

**解决**: 
1. 使用 `wait_for_selector` 等待关键元素
2. 增加等待时间
3. 检查页面是否完全加载

```python
# 等待商品详情页面完全加载
await page.wait_for_selector('button:has-text("Add to cart"), button:has-text("加入购物车")', 
                             timeout=15000, state='visible')
```

### 方案 4: 使用更通用的选择器

**问题**: 不同商品可能使用不同的组件

**解决**: 使用更通用的选择器策略：
