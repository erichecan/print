### 阶段 2: 修复添加购物车功能 ✅

#### 2.1 修复 API 调用 credentials
**文件**: `apps/web/src/lib/api.ts`
**问题**: API 调用缺少 `credentials: 'include'`，导致 sessionId cookie 无法传递
**修复**: 在 `api()` 函数的 config 中添加 `credentials: 'include'`

**关键代码**:
```typescript
const config: RequestInit = {
  method,
  headers: { ... },
  signal: controller.signal,
  credentials: 'include', // [2025-12-19 02:50:00] 修复：购物车 API 需要 sessionId cookie
};
```

#### 2.2 修复 BuyBox.tsx 中的硬编码 productId
**文件**: `apps/web/src/components/product/detail/BuyBox.tsx`
**问题**: `handleAddToCart` 和 `handleBuyNow` 中硬编码了 `productId: 'prod-001'`
**修复**: 
- 使用 props 传入的 `productId`，如果没有则使用 fallback
- 在 `ProductDetail.tsx` 中传递实际的 `apiProduct?.id` 给 BuyBox 组件

**关键代码**:
```typescript
// BuyBox.tsx
const payload = {
  productId: productId || 'prod-001', // [2025-12-19 02:50:00] 使用实际的 productId
  // ...
};

// ProductDetail.tsx
<BuyBox
  // ... other props
  productId={apiProduct?.id} // [2025-12-19 02:50:00] 传递实际的 productId
/>
```
