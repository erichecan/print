## ✅ 修复内容

### 问题描述
联系页面（`/contact`）的 "Send Message" 功能原本只发送邮件通知，不会在 admin 后台显示通知。用户希望它与 "Chat now"（留言本）使用相同的逻辑，即在 admin 后台显示通知。

### 修复方案
将联系页面的表单提交改为使用与留言本相同的 API（`/api/guest-messages`），这样：
1. 留言会保存到数据库（`GuestMessage` 模型）
2. 会在 admin 后台的 notifications 页面显示
3. 同时也会发送邮件通知

---

## 📝 修改的文件

### 1. `apps/web/src/app/contact/ContactClient.tsx`

**修改内容**:
- 移除了 `contactApi` 的导入
- 添加了 `apiPost` 的导入（与 `GuestBookForm` 相同）
- 将 `handleSubmit` 函数中的 API 调用从 `contactApi.submit()` 改为 `apiPost('/api/guest-messages', ...)`

**修改前**:
```typescript
import { contactApi } from '@/lib/api';

await contactApi.submit({
  name: formData.name,
  email: formData.email,
  // ...
});
```

**修改后**:
```typescript
import { apiPost } from '@/lib/apiClient';

await apiPost('/api/guest-messages', {
  name: formData.name,
  email: formData.email,
  // ...
});
```

## 🔄 工作流程

### 用户提交联系表单
1. 用户在 `/contact` 页面填写表单
2. 点击 "Send Message" 按钮
3. 表单数据通过 `POST /api/guest-messages` 提交到后端

### 后端处理
1. **验证数据**: 检查必填字段（name, email, message）
2. **保存到数据库**: 创建 `GuestMessage` 记录，状态为 `UNREAD`
3. **发送邮件通知**: 发送通知邮件给支持团队（可选，失败不影响保存）
4. **返回成功响应**: 返回 201 状态码和消息 ID

### Admin 后台显示
1. **Notifications 页面**: 在 `/admin/notifications` 页面可以看到新的留言
2. **状态管理**: 可以标记为已读、归档或删除
3. **未读计数**: 未读留言会显示红色边框和未读计数
