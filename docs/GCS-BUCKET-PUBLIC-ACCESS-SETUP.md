# GCS Bucket 公开访问配置指南

## 📋 关于公开访问对话框

在创建 GCS Bucket 时，GCP 会显示一个安全警告对话框，这是正常的。由于我们需要图片可以公开访问（用于网站显示），需要进行特殊配置。

## ✅ 正确的配置步骤

### 步骤 1：创建 Bucket 时的设置

当看到"系统将禁止公开访问"对话框时：

1. **不要勾选"禁止公开访问此存储桶"**（默认不勾选即可）
   - 这个选项是全局级别的保护，我们会在对象级别设置公开访问

2. **点击"确认"继续创建**
   - 这个对话框只是警告，不是阻止操作

### 步骤 2：创建后的权限配置（重要！）

创建 Bucket 后，需要设置对象级别的公开读取权限：

1. **进入 Bucket**
   - 在 GCP 控制台 Storage → Buckets 中找到刚创建的 Bucket

2. **设置对象级别公开访问**
   - 点击 Bucket 名称进入详情
   - 点击 "权限" (Permissions) 标签
   - 点击 "授予访问权限" (Grant Access)
   - 配置：
     ```
     新主体 (New principals): allUsers
     角色 (Role): Storage Object Viewer（存储对象查看者）
     ```
   - 点击 "保存"
   - 确认警告提示（这是正常的，因为我们确实需要公开访问图片）

### 步骤 3：验证配置

配置完成后，图片应该可以通过以下 URL 访问：
```
https://storage.googleapis.com/print-main-product-images/product/xxx/main.png
```

## 🔒 安全说明

虽然我们允许对象公开读取，但：
- ✅ 只有上传的对象可以被公开访问
- ✅ 无法通过公开 URL 列出 Bucket 内容
- ✅ 无法修改或删除对象（只读权限）
- ✅ 这符合静态资源（图片）的常见使用场景

## ⚠️ 常见问题

### Q: 这个对话框是什么意思？
A: GCP 的安全提示，默认建议禁止公开访问。但我们的图片需要公开显示，所以需要在对象级别允许公开读取。

### Q: 勾选"禁止公开访问"会怎样？
A: 如果勾选，即使设置了对象级别权限，图片也无法公开访问。所以不要勾选这个选项。

### Q: 如何确保只有图片公开，其他文件不公开？
A: 在对象级别设置的 `Storage Object Viewer` 权限只影响单个对象（文件），不勾选全局"禁止公开访问"不会自动公开所有文件，只有我们明确设置权限的对象才会公开。

## 📝 配置完成后的验证

运行以下命令验证 Bucket 可以访问：

```bash
gsutil ls gs://print-main-product-images
```

如果命令成功（即使返回空列表），说明 Bucket 已正确创建。
