# 购物车问题修复说明

**创建时间**: 2025-01-29 00:30:00

## 问题描述

用户反馈：
1. 添加购物车成功的提示语太长，需要简化
2. 虽然提示添加成功了，但是购物车页面是空的

## 修复内容

### 1. 简化提示语 ✅
- **位置**: `apps/web/src/app/products/[slug]/ProductDetailContent.tsx`
- **修改**: 将 `${quantity} item${quantity > 1 ? 's' : ''} added to cart!` 改为 `添加购物车成功`
- **影响**: 用户界面更加友好

### 2. 修复 Cookie 跨域配置 ✅
- **位置**: `backend/src/middleware/auth.js`
- **问题**: 生产环境中，前端和后端在不同域名（Cloud Run），使用 `sameSite: 'lax'` 导致 cookie 无法跨域传递
- **修复**:
  - 在生产环境中使用 `sameSite: 'none'` 和 `secure: true`
  - 添加 `path: '/'` 确保 cookie 在所有路径下可用
  - 与 `authController.js` 中的 `getCookieOptions()` 保持一致

```javascript
const isProduction = process.env.NODE_ENV === 'production';
res.cookie('sessionId', sessionId, {
  httpOnly: true,
  secure: isProduction, // 生产环境必须使用 HTTPS
  sameSite: isProduction ? 'none' : 'lax', // 跨域请求需要 'none'
  maxAge: 30 * 24 * 60 * 60 * 1000, // 30 days
  path: '/', // 确保 cookie 在所有路径下可用
});
```

### 3. 添加详细日志用于调试 ✅
- **位置**: `backend/src/controllers/cartController.js`
- **添加的日志**:
  - 添加商品时记录 sessionId、userId、cartId
  - 获取购物车时记录 sessionId、userId、cartId、itemCount
  - 记录是否有 sessionCookie
- **用途**: 帮助排查购物车为空的问题

## 购物车为空问题的可能原因

1. **SessionId Cookie 未正确传递**
   - 已修复：Cookie 配置已支持跨域
   
2. **添加和获取购物车时使用了不同的 sessionId**
   - 已添加日志：可以通过日志对比 sessionId 是否一致

3. **获取购物车时创建了新的空购物车**
   - 已添加日志：记录购物车ID和商品数量
