# 性能优化方案

**创建时间**: 2025-01-29 00:00:00

## 问题分析

### 当前问题

1. **Cloud Run 冷启动慢**
   - `minScale: "0"` 导致服务空闲时缩放到零
   - 首次请求需要冷启动（5-30秒）
   - 解决方案：设置 `minScale: "1"` 保持至少一个实例运行

2. **没有 Redis 缓存**
   - 所有产品查询都直接访问数据库
   - 数据库连接延迟（Neon 跨区域）
   - 解决方案：配置 Redis 缓存或使用内存缓存

3. **数据库连接优化不足**
   - Prisma 连接池配置不完整
   - Neon 数据库连接可能需要优化
   - 解决方案：优化数据库连接池配置

4. **静态资源未优化**
   - 图片没有使用 CDN
   - 前端资源没有缓存策略
   - 解决方案：配置 Cloud CDN 或优化缓存头

## 优化方案

### 方案 1：快速优化（立即实施）

#### 1.1 设置 Cloud Run minScale = 1

**优点**：
- 消除冷启动延迟
- 响应时间立即改善

**缺点**：
- 增加成本（需要保持至少一个实例运行）

**实施步骤**：
1. 修改 `backend/cloud-run.yaml` 和 `apps/web/cloud-run.yaml`
2. 将 `autoscaling.knative.dev/minScale: "0"` 改为 `"1"`
3. 重新部署服务

#### 1.2 优化数据库连接

**实施步骤**：
1. 检查 Neon 数据库连接字符串是否包含连接池参数
2. 在 Prisma schema 中配置连接池
3. 添加连接超时和重试机制

#### 1.3 启用内存缓存（无需 Redis）

**实施步骤**：
1. 创建简单的内存缓存模块
2. 在 productController 中使用内存缓存
3. 设置合理的 TTL（5-10分钟）

### 方案 2：中期优化（1-2周）

#### 2.1 配置 Redis 缓存

**选项 A：使用 Cloud Memorystore（GCP 托管 Redis）**
- 优点：完全托管，高可用
- 缺点：需要付费

**选项 B：使用 Upstash Redis（Serverless Redis）**
- 优点：免费套餐，按需付费
- 缺点：需要配置外部服务

#### 2.2 优化数据库查询

1. 添加数据库索引
2. 优化复杂查询
3. 使用数据库视图或物化视图

### 方案 3：长期优化（1个月+）

1. 配置 Cloud CDN
2. 图片优化和懒加载
3. 前端代码分割和预加载
4. 使用 Cloud Run 的并发配置优化

## 立即实施的优化

### 优化 1：设置 minScale = 1

修改 Cloud Run 配置，保持至少一个实例运行：

```yaml
annotations:
  autoscaling.knative.dev/minScale: "1"  # 改为 1，消除冷启动
  autoscaling.knative.dev/maxScale: "5"
```

### 优化 2：添加内存缓存

创建简单的内存缓存模块，替代 Redis：

```javascript
// backend/src/config/memoryCache.js
class MemoryCache {
  constructor() {
    this.cache = new Map();
  }
  
  get(key) {
    const item = this.cache.get(key);
    if (!item) return null;
    if (Date.now() > item.expiry) {
      this.cache.delete(key);
      return null;
    }
    return item.value;
  }
  
  set(key, value, ttl = 300) {
    this.cache.set(key, {
      value,
      expiry: Date.now() + ttl * 1000
    });
  }
}

module.exports = new MemoryCache();
```

### 优化 3：优化数据库连接池

在 DATABASE_URL 中添加连接池参数：

```
postgresql://user:pass@host/db?connection_limit=5&pool_timeout=20
```
