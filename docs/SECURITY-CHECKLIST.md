# 安全与监控检查表

<!-- 更新于 2025-11-10 14:13:30 -->

## 安全配置
- [ ] 所有环境变量存储在安全密钥管理器（如 AWS Secrets Manager）
- [ ] JWT 密钥长度 ≥ 32 字符，定期轮换
- [ ] 启用 HTTPS / HSTS，禁止混合内容
- [ ] CORS 限制为可信域名
- [ ] Helmet 中启用常用安全头
- [ ] 速率限制策略已根据需求调整
- [ ] Webhook 验签密钥安全保存
- [ ] 数据库连接启用 SSL/TLS

## 监控与告警
- [ ] API 暴露 `/healthz` 或 `/status` 健康检查
- [ ] 应用日志输出到集中式管道（ELK/CloudWatch 等）
- [ ] Stripe Webhook 失败告警
- [ ] 数据库备份与恢复流程演练完成
- [ ] 指标监控（请求量、错误率、延迟、队列长度）
- [ ] 关键流程（注册、下单、支付）具备合规审计日志
