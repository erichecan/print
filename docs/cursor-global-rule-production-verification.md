# Cursor 全局规则：生产验证强提醒

本规则用于：**每次完成新功能或部署到 GCP 后，强提醒你做一次线上验证**，避免生产环境已出事故却不知道。

---

## 一、如何设为「全局规则」（对所有项目生效）

1. 打开 **Cursor** → **Settings**（或 `Cmd + ,`）
2. 左侧选 **Cursor Settings** → **General**
3. 找到 **Rules for AI**
4. 在文本框内粘贴下面「二、规则正文」中的整段内容，保存

之后在任何项目里，只要满足条件（新功能完成或部署到 GCP），AI 都会在回复末尾给出生产验证强提醒。

---

## 二、规则正文（复制到 Rules for AI）

```
【生产验证强提醒 - 全局规则】

当发生以下任一情况时，你必须在回复末尾单独输出一段「生产验证强提醒」，不得省略：
1) 完成新功能（合并/上线或标记完成）；
2) 部署到 GCP（Cloud Run、App Engine 等）。

强提醒格式（必须明显、单独成段）：

---
⚠️ 【必须】生产环境验证

请立刻做一次线上验证，避免部署后生产已出问题却不知道：

- [ ] 打开生产环境 URL（网站/API），确认本次改动是否正常
- [ ] 按需验证关键流程：登录、主功能、支付/下单等
- [ ] 若有异常，立即回滚或修复，不要让生产长时间处于故障状态

---
```

---

## 三、本项目中已生效的规则

当前仓库已在 **`.cursor/rules/production-verification.mdc`** 中配置了同一条规则（`alwaysApply: true`），因此在本项目内即使未设置全局 Rules for AI，也会收到该强提醒。

若希望**所有项目**都生效，请按「一」将「二」的规则正文添加到 Cursor 的全局 **Rules for AI**。
