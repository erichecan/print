## 如果部署失败

### 检查 Cloud Build 日志

```bash
# 获取最新的构建 ID
BUILD_ID=$(gcloud builds list --limit=1 --project=moonlit-gamma-479502-r6 --format="value(id)")

# 查看构建日志
gcloud builds log $BUILD_ID --project=moonlit-gamma-479502-r6
```

### 手动运行 Seed

如果自动 seed 失败，可以手动运行：

```bash
# 连接到 Cloud Run 服务并执行 seed
gcloud run services update print-main-backend \
  --region=us-central1 \
  --project=moonlit-gamma-479502-r6 \
  --exec-command="npx sequelize-cli db:seed:all"
```

或者使用 fix-admin-user.js 脚本创建用户。
