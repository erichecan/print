# 购物车和 Buy Now 功能修复总结

**修复时间**: 2025-01-28 23:50:00

## 发现的问题

### 1. 错误的 Prisma 模型名
**问题**: 后端代码中使用了错误的 Prisma 模型名 `productVariant`，但实际模型名是 `variant`。

**影响范围**:
- `backend/src/controllers/cartController.js` - 添加商品到购物车时无法查询 variant
- `backend/src/services/inventoryService.js` - 库存检查和更新功能全部失效

**修复**:
- `cartController.js`: 将 `prisma.productVariant.findUnique` 改为 `prisma.variant.findUnique`
- `inventoryService.js`: 将所有 `prisma.productVariant` 改为 `prisma.variant`（共 6 处）

### 2. 价格计算问题
**问题**: `basePrice` 在数据库中是以 cents（分）为单位存储的（Int 类型），但代码中直接与 `priceAdjustment`（Decimal，美元）相加，单位不一致。

**修复**:
- 在 `cartController.js` 中添加价格转换逻辑：
  ```javascript
  const basePriceInDollars = Number(variant.product.basePrice) / 100; // Convert cents to dollars
  const priceAdjustmentInDollars = Number(variant.priceAdjustment || 0); // Already in dollars
  const price = basePriceInDollars + priceAdjustmentInDollars; // Final price in dollars
  ```

### 3. 图片 URL 字段名错误
**问题**: 购物车返回的商品缩略图使用了错误的字段名 `imageUrl`，但 `ProductImage` 模型使用的是 `url` 字段。

**修复**:
- 将 `item.variant.product.images[0]?.imageUrl` 改为 `item.variant.product.images[0]?.url`

## 修复的文件
