# ⚠️ 需要先安装 Git！

## 🔧 安装 Git for Windows

### 步骤 1: 下载 Git
访问官网并下载：
**https://git-scm.com/download/win**

点击 "Download for Windows" 按钮

### 步骤 2: 安装 Git
运行下载的安装程序：
1. ✅ 接受许可协议
2. ✅ 选择安装位置（使用默认）
3. ✅ 选择组件（使用默认设置）
   - [x] Git Bash Here
   - [x] Git GUI Here
   - [x] Associate .git* files with the default editor
   - [x] Add a Git Bash profile to Windows Terminal
4. ✅ 选择默认编辑器（使用 "Use Visual Studio Code" 或 Notepad++）
5. ✅ 调整 PATH 环境变量（使用 "Git from the command line and also from 3rd-party software"）
6. ✅ 其他选项使用默认设置
7. ✅ 点击 "Install"
8. ✅ 等待安装完成
9. ✅ 点击 "Finish"

### 步骤 3: 验证安装
**关闭当前的 PowerShell，重新打开**，然后运行：

```powershell
git --version
```

应该显示：`git version 2.x.x`

### 步骤 4: 配置 Git（首次使用）
```powershell
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

### 步骤 5: 安装完成后
安装完成后，**重新运行之前的命令**或告诉我，我会帮您继续推送。
