# 域名验证快速指南（cPanel）

## 🎯 目标

验证 `souvenirplusinc.com` 域名所有权，以便在 GCP 创建自定义域名映射。

---

## ⚡ 快速步骤（5 分钟）

### 1️⃣ 访问 Google Search Console

访问：https://search.google.com/search-console

使用与 GCP 项目相同的 Google 账号登录。

### 2️⃣ 添加域名属性

1. 点击 **"添加属性"** 按钮（左上角）
2. 选择 **"域名"** 类型（**不是** "URL 前缀"）
3. 输入：`souvenirplusinc.com`
4. 点击 **"继续"**

### 3️⃣ 获取验证记录

Google 会显示一个 TXT 记录，类似：
```
google-site-verification=AbCdEfGhIjKlMnOpQrStUvWxYz1234567890
```

**复制完整的验证字符串**（包括 `google-site-verification=` 部分）

### 4️⃣ 在 cPanel 添加 TXT 记录

1. 登录 cPanel：`https://fivelionshvac.com:2083`
2. 找到并点击 **"Zone Editor"** 或 **"DNS 区域编辑器"**
3. 选择域名：`souvenirplusinc.com`
4. 点击 **"+ TXT Record"** 或 **"添加 TXT 记录"**
5. 填写：
   - **Name**: `@` （或留空，表示根域名）
   - **Type**: `TXT`
   - **Value**: `google-site-verification=AbCdEfGhIjKlMnOpQrStUvWxYz1234567890`（完整的验证字符串）
   - **TTL**: `3600`
6. 点击 **"添加记录"** 保存

### 5️⃣ 验证域名

1. 返回 Google Search Console 页面
2. 点击 **"验证"** 按钮
3. 等待验证结果

**如果验证失败**：
- 等待 5-10 分钟（DNS 传播需要时间）
- 检查 TXT 记录是否正确添加
- 可以运行 `dig souvenirplusinc.com TXT` 检查记录是否生效

---

## ✅ 验证成功后

验证成功后，就可以创建 GCP 域名映射了：

```bash
# 创建前端域名映射
gcloud beta run domain-mappings create \
  --service=print-main-frontend \
  --domain=pod.souvenirplusinc.com \
  --region=us-central1 \
  --project=moonlit-gamma-479502-r6

# 创建后端域名映射
gcloud beta run domain-mappings create \
  --service=print-main-backend \
  --domain=api.souvenirplusinc.com \
  --region=us-central1 \
  --project=moonlit-gamma-479502-r6
```

## 🔍 验证 TXT 记录是否生效

在终端运行：

```bash
dig souvenirplusinc.com TXT
```

如果看到包含 `google-site-verification` 的记录，说明 DNS 记录已生效。

## ⚠️ 常见问题

### Q: 验证失败怎么办？

A: 
1. 等待 10-30 分钟让 DNS 传播
2. 确认 TXT 记录的 Name 字段是 `@` 或留空
3. 确认 Value 包含完整的 `google-site-verification=...` 字符串
4. 检查是否使用了正确的 Google 账号（必须与 GCP 项目账号相同）

### Q: 找不到 Zone Editor？

A: 在 cPanel 搜索框输入 "zone" 或 "dns" 可以快速找到。

### Q: TXT 记录已经存在怎么办？

A: 可以保留现有的 TXT 记录，添加新的验证记录。一个域名可以有多个 TXT 记录。
