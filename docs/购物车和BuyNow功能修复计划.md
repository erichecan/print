# 购物车和 Buy Now 功能修复计划

**创建时间**: 2025-01-28 23:30:00

## 目标

检查和修复购物车添加商品功能以及 Buy Now（立即购买）功能，确保用户可以正常添加商品到购物车并完成购买流程。

## 问题分析

### 需要检查的功能点

1. **添加商品到购物车（Add to Cart）**
   - 商品详情页的 "Add to cart" 按钮功能
   - Variant 选择（颜色、尺寸）是否正确
   - 数量选择是否正确
   - API 调用是否成功
   - 错误处理是否完善

2. **立即购买（Buy Now）**
   - 商品详情页的 "Buy Now" 按钮功能
   - 添加到购物车后是否正确跳转到结算页
   - 错误处理是否完善

3. **后端 API 端点**
   - `POST /api/cart/items` - 添加商品到购物车
   - 库存检查
   - 价格快照
   - Session 管理

4. **前端状态管理**
   - CartContext 是否正确更新
   - 购物车图标数量是否正确显示
   - Toast 提示是否正常
