## 注意事项

1. **GCP Console 错误**：这些错误来自 Google 内部服务，无法直接修复。我们的错误过滤器会在控制台中隐藏这些错误，但它们不会影响应用功能。

2. **PerformanceObserver 警告**：这些警告通常来自第三方库或浏览器扩展，错误过滤器会抑制这些警告的显示。

3. **资源预加载**：Next.js 会自动预加载一些资源。我们已经优化了配置以减少不必要的预加载，但某些预加载警告可能仍然会出现（通常可以被忽略）。

4. **测试环境**：建议在 GCP Console 预览环境中进行测试，因为某些错误只在该环境中出现。
