### 2. 🔄 "Place Order" 按钮无法点击（待验证）

#### 问题分析
按钮的禁用条件：
- `!stripe` - Stripe 未加载
- `isSubmitting` - 正在提交
- `isFetchingRates` - 正在获取运费
- `isCalculatingTotals` - 正在计算总计
- `!cardComplete` - 卡片信息未完成

#### 已做改进
- **文件**：`apps/web/src/app/checkout/page.tsx`
- **改进**：添加了按钮的 `title` 属性，显示禁用原因，方便调试

#### 调试建议
如果按钮仍然无法点击，请检查：
1. **Stripe 加载状态**：在浏览器控制台输入 `window.Stripe` 检查 Stripe 是否已加载
2. **cardComplete 状态**：在卡片输入框中输入完整的测试卡号（例如：`4242 4242 4242 4242`），观察按钮是否变为可点击
3. **加载状态**：检查 Network 标签页，确认没有持续的 API 请求导致 `isFetchingRates` 或 `isCalculatingTotals` 为 true
