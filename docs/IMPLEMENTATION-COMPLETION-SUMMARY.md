## 📝 技术实现要点

### Names & Numbers 视图映射
- 使用 `setView()` 切换到目标视图
- 使用 `applySnapshotToCanvas()` 加载视图画布
- 使用 `setCanvas()` 保存视图画布状态
- 文本根据 `nameSide` 和 `numberSide` 添加到正确的视图

### 动画实现
- 使用 CSS `@keyframes` 定义动画
- 使用 CSS `transition` 实现过渡效果
- 使用 `backdrop-filter` 实现背景模糊
- 使用 `transform` 实现平移和缩放效果
