## 功能特性

### 后端 API

**POST `/api/admin/users`** - 创建新用户

**请求体**:
```json
{
  "email": "user@example.com",
  "password": "optional-password",  // 可选，如果不提供则自动生成临时密码
  "firstName": "John",              // 可选
  "lastName": "Doe",                // 可选
  "phone": "+1 (555) 123-4567",     // 可选
  "role": "CUSTOMER",               // 可选，默认为 "CUSTOMER"（"ADMIN" 或 "CUSTOMER"）
  "emailVerified": true             // 可选，默认为 false
}
```

**响应**:
```json
{
  "user": {
    "id": "uuid",
    "email": "user@example.com",
    "firstName": "John",
    "lastName": "Doe",
    "fullName": "John Doe",
    "phone": "+1 (555) 123-4567",
    "role": "CUSTOMER",
    "emailVerified": true,
    "createdAt": "2025-01-28T...",
    "updatedAt": "2025-01-28T..."
  }
}
```

**验证规则**:
- 邮箱必填且必须是有效格式
- 邮箱必须唯一
- 如果提供密码，必须至少 8 个字符
- 如果未提供密码，系统会自动生成一个临时密码（用于邀请场景）
- 角色必须是 "CUSTOMER" 或 "ADMIN"，默认 "CUSTOMER"
- `emailVerified` 为布尔值，默认 `false`

## 使用说明

### 创建新用户

1. 登录 Admin 后台
2. 导航到 "Users" 页面
3. 点击右上角的 "+ Invite User" 按钮
4. 填写用户信息：
   - Email（必填）
   - Password（可选，不填写则系统生成临时密码）
   - First Name / Last Name（可选）
   - Phone（可选）
   - Role（选择 Customer 或 Admin）
   - Account Status（勾选表示邮箱已验证，账户立即激活）
5. 点击 "Create User" 按钮
6. 用户创建成功后，列表会自动刷新

### 邀请用户（不提供密码）

如果要邀请用户：
1. 填写邮箱
2. 不填写密码（或留空）
3. 不勾选 "Email Verified"
4. 系统会自动生成临时密码，用户需要通过邮件验证来设置自己的密码

### 直接创建已激活用户

如果要直接创建已激活的用户：
1. 填写所有必填信息
2. 勾选 "Email Verified" 复选框
3. 用户创建后即可立即使用

## 数据库持久化

所有用户数据都通过 Prisma ORM 保存到 PostgreSQL 数据库：

- 用户信息保存在 `users` 表
- 密码通过 bcrypt 加密存储
- 角色存储为枚举值（CUSTOMER 或 ADMIN）
- 激活状态存储在 `email_verified` 字段
- 创建和更新时间自动记录

## 安全性

1. **权限控制**: 只有 Admin 用户可以创建用户（通过 `requireAdmin` 中间件）
2. **密码加密**: 使用 bcrypt 进行密码哈希，安全性高
3. **邮箱验证**: 支持邮箱格式验证和唯一性检查
4. **输入验证**: 所有输入都经过验证，防止无效数据
