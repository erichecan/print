# 结账页按钮诊断说明

## 问题描述

用户反馈：
1. Place Order 按钮不能点击
2. 优惠券 Apply 按钮不能点击

## 已添加的调试日志

### 1. Place Order 按钮状态日志
- **位置**: `apps/web/src/app/checkout/page.tsx` - useEffect 钩子
- **输出内容**:
  - `disabled`: 按钮是否被禁用
  - `stripe`: Stripe 是否已加载
  - `isSubmitting`: 是否正在提交订单
  - `isFetchingRates`: 是否正在获取运费
  - `isCalculatingTotals`: 是否正在计算总计
  - `cardComplete`: 卡片信息是否填写完整
  - `disabledReason`: 按钮被禁用的具体原因

### 2. Apply Coupon 按钮状态日志
- **位置**: `apps/web/src/app/checkout/page.tsx` - useEffect 钩子
- **输出内容**:
  - `disabled`: 按钮是否被禁用
  - `applyingCoupon`: 是否正在应用优惠券
  - `hasCouponCode`: 是否有优惠券代码
  - `addressReady`: 地址是否填写完整
  - `disabledReason`: 按钮被禁用的具体原因

### 3. addressReady 状态日志
- **位置**: `apps/web/src/app/checkout/page.tsx` - addressReady useMemo
- **输出内容**:
  - 完整的地址字段验证状态
  - 每个必填字段是否已填写

### 4. 卡片输入状态变化日志
- **位置**: `apps/web/src/app/checkout/page.tsx` - CardElement onChange
- **输出内容**:
  - `complete`: 卡片信息是否完整
  - `error`: 错误信息（如果有）
  - `empty`: 是否为空
  - `brand`: 卡片品牌

## 按钮禁用条件

### Place Order 按钮
```typescript
disabled={!stripe || isSubmitting || isFetchingRates || isCalculatingTotals || !cardComplete}
```

可能的原因：
1. **!stripe**: Stripe 未加载
2. **isSubmitting**: 正在提交订单
3. **isFetchingRates**: 正在获取运费
4. **isCalculatingTotals**: 正在计算总计
5. **!cardComplete**: 卡片信息未填写完整

### Apply Coupon 按钮
```typescript
disabled={applyingCoupon || !couponCode.trim() || !addressReady}
```

可能的原因：
1. **applyingCoupon**: 正在应用优惠券
2. **!couponCode.trim()**: 没有输入优惠券代码
3. **!addressReady**: 地址信息未填写完整

## 测试步骤

1. **部署完成后**，访问结账页面：`https://print-main-frontend-hsbqzlnkxa-uc.a.run.app/checkout`

2. **打开 Chrome DevTools** (F12 或 Cmd+Option+I)

3. **查看 Console 标签页**，查找以下日志：
   - `[Checkout Debug] Button states:` - 按钮状态
   - `[Checkout Debug] addressReady:` - 地址状态
   - `[Checkout Debug] Card state changed:` - 卡片状态变化

4. **填写表单**，观察日志变化：
   - 填写地址信息，查看 `addressReady` 是否变为 `true`
   - 填写卡片信息，查看 `cardComplete` 是否变为 `true`
   - 输入优惠券代码，查看 `hasCouponCode` 是否为 `true`

5. **根据日志中的 `disabledReason`**，确定按钮被禁用的具体原因

## 预期修复

根据诊断结果，可能需要修复的问题：

1. **Stripe 未加载**: 检查 Stripe publishable key 配置
2. **cardComplete 为 false**: 检查 Stripe CardElement 的 onChange 事件是否正常工作
3. **addressReady 为 false**: 检查地址字段验证逻辑
4. **isFetchingRates 或 isCalculatingTotals 一直为 true**: 检查 API 调用是否正常完成

## 下一步

部署完成后，使用 Chrome DevTools 检查控制台日志，根据 `disabledReason` 定位具体问题，然后修复。
