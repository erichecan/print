---
description: Activates the Superpowers workflow for brainstorming, planning, and TDD execution.
---

1. View the file `~/.agent/skills/superpowers/SKILL.md` (or the specific sub-skill needed) to load the skill context.
2. The `superpowers` skill is a collection of sub-skills. Based on your current need (brainstorming, planning, executing), select the appropriate sub-skill from `~/.agent/skills/superpowers/skills/` (e.g., `brainstorming/SKILL.md` or `using-superpowers/SKILL.md`).
3. Follow the instructions in the selected skill to proceed.
